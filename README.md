# 📚 DSA — Basics to Advanced

A personal collection of **Data Structures and Algorithms** problems solved in **C++**, progressing from foundational concepts to advanced techniques. This repository serves as my DSA learning journal and problem-solving reference.

## 🧠 Topics Covered

### 🔢 Arrays
Basics of arrays — insertion, deletion, traversal, reversal, sum, max/min, swapping, and alternating elements.

### 🔍 Searching
Linear Search and Binary Search, including variants like first/last occurrence, count of occurrences, element with max frequency, pivot finding in rotated arrays, and peak element detection in mountain arrays.

### 📊 Sorting
Classic sorting algorithms — Bubble Sort, Selection Sort, and 0-1 Sort (Dutch National Flag problem).

### 🧩 Problem Solving
Higher-order problems built on the above foundations — Book Allocation (Binary Search on Answer), Pair Sum, and Square Root computation via Binary Search.

## 🚀 How to Run

**1. Clone the repository**
```bash
git clone https://github.com/datsaryan/DSA_basics_to_adv.git
cd DSA_basics_to_adv
```

**2. Compile any file**
```bash
g++ filename.cpp -o output
```

**3. Run**
```bash
./output
```

> Example:
> ```bash
> g++ binarysearch.cpp -o binarysearch
> ./binarysearch
> ```
